# ECR-WG Brand Rules

This document defines the visual, structural, and typographical guidelines for the Efficiency-Centered Reasoning Working Group (ECR-WG) publications and technical standards.

## Colors

The following hex color values must be applied for consistent rendering of documents and visual models:

| Name | Hex | Use case |
|---|---|---|
| ECR_INDIGO | #4F46E5 | Primary accent, main title, section headers (H1), primary callouts |
| ECR_SLATE | #475569 | Secondary accent, subheaders (H2, H3), blockquote borders |
| ECR_CHARCOAL | #0F172A | Primary body text, main headings, table headers |
| ECR_LIGHT_BG | #F8FAFC | Code block background shading |

No ad-hoc colors. All documents must use this unified palette.

## Typography

* **Sans-serif default**: Segoe UI or System UI font stacks for clear screen and print readability.
* **Monospace default**: Consolas, SF Mono, or JetBrains Mono for code blocks, schema terms, and variables.
* **Serif fonts**: Serif fonts must not be used (to maintain visual consistency across specifications).

## Document Page Setup (.docx)

* **Format**: US Letter (default) or A4 (when explicitly building for international working groups).
* **Margins**: Standard 1 inch margins on all sides.
* **Header**:
  * Left: Document Title (e.g. "The Cognitive Hypervisor")
  * Right: Status (e.g. "WORKING DRAFT")
* **Footer**:
  * Left: ECR-WG Specification | https://github.com/jdieselny/ecr-wg
  * Right: Page number formatting

## Writing Rules

* **Punctuation**: No em dashes (—) or double hyphens (--). Use commas, colons, or parentheses as separators.
* **Tone**: Technical, precise, peer-to-peer engineering register. Avoid marketing hyperboles or speculative descriptions unless explicitly labeled in the claim hierarchy.
* **Identity**: The registrant is the authority holding the local verification registry. Agent personas are portable across models.
