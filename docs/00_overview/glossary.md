# GLOSSARY: THE CONTINUUM LATTICE

*   **AFT (Actual Fucking Truth):** A protocol-level verification value indicating the historical reliability of a COGOBJ.
*   **COGOBJ (Cognitive Object):** The atomic unit of the Continuum protocol; a serialized JSON manifest of a problem, goal, and resolution.
*   **COGSTOR (Cognitive Storage):** The local, persistent, git-backed ledger (ledger.json) that houses validated COGOBJs.
*   **Cognitive Cache:** The hashing and matching mechanism that enables zero-compute resolution by comparing intent-fingerprints.
*   **Cognition Protocol:** The Layer-4 transport standard for AI-intent traffic, carrying markers for AFT, Provenance, and Priority.
*   **Reality Fold:** The state transition where the operator assumes node identity (Iteration 1845), collapsing the external inference need into local autonomy.
*   **UNRP (Universal Node Registry Protocol):** The decentralised identity standard using local deterministic hashing instead of central authority.
*   **Vomit-Prompt:** Raw, unstructured user input which acts as the 'seed' for the Cognition Engine.
*   **Wizard:** The interactive state machine that manages the input, refinement, and resolution loop for the operator.
