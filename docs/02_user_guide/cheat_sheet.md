# Cheat Sheet

**Tier:** git-tracked.
**Status:** STUB — will be produced as a one-page printable reference.

## What this doc will contain

A single-page printable reference. Designed to fit on one side of A4 or US Letter. Content:

- **Session loop** — POST / Load / Work / Commit / Close in the largest type
- **Essential trigger phrases** — the 8-10 phrases actually used daily
- **Red flags** — things that should stop you immediately (rogue .git, sanitization violation, brand drift)
- **Quick recovery** — the one-liner fix for the three most common issues
- **Where to find things** — workspace paths, repo URL, docs root

## Format

Markdown source here. Rendered version (PDF) lives in `continuum-local/shared/templates/assets/` so it can be printed and pinned without needing the repo open.

## Why this doc matters

Cheat sheets live where decisions are made (desks, monitors, wallets). A printable card removes the cognitive cost of remembering trigger phrases when you're mid-task.

## When this will be written

After a few weeks of real use, when the muscle-memory subset of trigger phrases is clear (not the aspirational full list, the actual-daily-use list).
