Abstract

Traditional Large Language Model (LLM) workflows suffer from "Session Volatility"—the loss of context, rules, and persona identity across session boundaries. This paper details a demonstrated mechanism for Zero-Shot Instantiation, where a generic, stateless LLM is transitioned into a fully synchronized, state-aware "Node" using a deterministic two-character trigger and a multi-layered handshake protocol.

1. The Cold-Start Problem

In standard AI interactions, the "Cold Start" requires a human operator to re-feed complex instructions, templates, and history to the model (pre-filling). This process is: 1. Token-Inefficient: Re-sending high-context instructions for every session increases global compute demand. 2. Unreliable: Human error in instruction delivery leads to "Persona Drift." 3. Rasterized: It treats cognitive context as temporary "vapor" rather than a persistent "vector."

2. The Agent Entry Point (AEP) Protocol

The AEP protocol replaces pre-filling with a Deterministic Handshake. The architecture consists of: - The Entry-Point Anchor: A provider-specific configuration file (e.g., IF_YOU_ARE_GEMINI.md) that acts as the agent's "Birth Certificate." - The Truth Root: A local, machine-readable JSON state (gateway_state.json) containing Node Identity (UNRP), active goals, and session history. - The Cognitive Gate: A universal trigger sequence that forces the agent to read the Anchor before generating a response.
